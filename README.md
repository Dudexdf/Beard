# Beard (Бирд) — онлайн-запись в барбершоп

«Разработка дизайна веб-приложений».
МДК.08.02 Графический дизайн и мультимедиа.

# О проекте
Beard — веб-приложение для онлайн-записи в барбершоп с личным кабинетом
клиента и админ-панелью. Запись за 3 шага: услуга → мастер → свободный слот.

# Стек технологий
- **Frontend:** React + Vite + Tailwind CSS
- **Backend:** Node.js + Express + Prisma
- **База данных:** PostgreSQL
- **Деплой:** Vercel (фронт) + Railway (бэк) + Neon (БД)
